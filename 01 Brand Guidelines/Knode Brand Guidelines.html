01The mark

Two blocks, one node.

The K is two blocks joined by a bridge: two connected ideas. It is drawn on a 10 × 25 cell grid, with the stem as an exact square and a single rounding rule: every corner, outward or inward, has a radius of one cell.

04System

One cell, one radius.

Everything in Knode, from the mark to the last icon, comes from the same rule. If something new follows it, it already belongs to the brand.

1 · The cell

Everything is drawn with square cells. Letters are 5 tall; icons 7 × 7; the mark 10 × 25 in half cells.

2 · The radius

Half a cell on every corner, convex or concave. A one-cell gap always ends in a semicircle, like the slots of the K.

3 · Two weights

A 2-cell stroke for the mark and Block. A 1-cell stroke for Line and the icons. They never mix within one piece.

4 · Slots, not lines

Detail is made by cutting into the mass (slots, notches, dots), not by adding strokes. No thin diagonals, no outlines.

developers / api and sdk

  
your map, as a local service.

  
Knode is local: your own machine serves the API with knode serve and the SDKs read the file directly. Nothing goes through Knode servers.

  
knode serve · local api
$ knode serve  --port 4747

[ok] serving map.knode at http://localhost:4747
     only on this machine. nothing leaves your mac.

$ curl localhost:4747/v1/nodes?q=brand

{
  "data": [ { "id": "n_8f2a", "title": "name and brand" } ],
  "total": 1
}
routes · v1
GET    /v1/nodes            list and search
GET    /v1/nodes/{id}       one node with its links
POST   /v1/nodes            create a node
POST   /v1/links            link two nodes
POST   /v1/import           import an export
GET    /v1/map              the whole map, as .knode

  
typescript · @knode/sdk
// typescript · @knode/sdk
import { open } from "@knode/sdk";

const map = await open("map.knode");
const node = map.create({ title: "new idea" });
map.link(node, map.search("brand")[0]);
await map.save();
swift · KnodeKit
// swift · KnodeKit
import KnodeKit

let map = try KnodeMap(url: file)
let node = map.create(title: "new idea")
try map.link(node, to: map.search("brand").first!)
try map.save()






  
developers / mcp

  
claude, inside your map.

  
With knode mcp, Claude and other MCP clients can search, read, create and link nodes in your map. It closes the loop: conversations become nodes, and nodes come back into the conversation.

  
setup
// claude_desktop_config.json
{
  "mcpServers": {
    "knode": { "command": "knode", "args": ["mcp"] }
  }
}

tools claude will see:
  search_nodes   read_node   create_node   link_nodes

    
in the conversation
you  what did we decide about the logo?
