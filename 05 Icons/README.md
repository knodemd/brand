# Icons

68 icons on a 7 × 7 grid with a one-cell stroke (the weight of Knode Line) and a half-cell
radius on every corner. Fills are kept for the mark and for active states. Import and Export
also cover download and upload.

- `SVG/` · `fill="currentColor"`, so they take the text colour in code and in Figma.
- `PDF/` · ink, vector, for Affinity, Illustrator and Keynote.
- `PNG/` · ink, paper and indigo at 64 and 256 px, transparent.
- `sprite.svg` · every icon as a `<symbol id="knode-…">` for the web.
- `icons.json` · the grid rows, to rebuild them anywhere.

Minimum size 16 px; draw them at multiples of 7 px for crisp edges (14, 21, 28…).

- **Brand and map**: Knode, Node, Connect, Map, Tree, Group, Link
- **Files**: File, Note, Folder, Import, Export, Save, Archive, Delete
- **Editing**: Edit, Text, Tasks, Copy, Cut, Paste, Undo, Redo, Select, Drag, Add
- **View**: Zoom in, Zoom out, Focus, Expand, Sidebar, Grid, List, Show, Hide, Pin
- **Navigation**: Home, Search, Filter, Sort, Menu, More, Back, Forward, Up, Down, Close, Done
- **Content**: Chat, Image, Calendar, History, Tag, Bookmark
- **Account and status**: Profile, People, Private, Cloud, Alerts, Info, Warning, Help, Settings
- **Web and developers**: Web, Mail, RSS, Code, Terminal
